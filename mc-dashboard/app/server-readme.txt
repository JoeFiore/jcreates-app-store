MC Dashboard server folder
==========================
Put your Minecraft Java server here — easiest way is the dashboard's
Import tab: upload a zip of the whole server (server.jar, mods/, config/,
world/) and it extracts here. A zip with one folder at the top is
flattened automatically. If the EULA is needed, accept it in the dashboard,
then press Start.

Backups land in backups/ inside this folder.
Minecraft players join on port 25565.
